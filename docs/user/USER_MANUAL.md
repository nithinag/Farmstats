# FARMSTATS User Manual

## Getting Started

### First Launch

When you open FARMSTATS for the first time, you will see a welcome carousel introducing the key features. Swipe through each page or tap **Skip** to go directly to the Dashboard.

### Navigation

FARMSTATS uses a bottom navigation bar with five main sections:

1. **Dashboard** — Your operational overview
2. **Expenses** — Financial outflows
3. **Batches** — Core silkworm batch management
4. **Inventory** — Stock and supplies
5. **Settings** — App configuration

Additional modules (Income, Labour, Feeding, Harvest, Reports, Notifications) are accessible through the Dashboard cards or the navigation menu.

---

## Core Workflows

### Creating a New Batch

1. Navigate to **Batches** from the bottom bar.
2. Tap the **+** floating action button.
3. Fill in:
   - Batch Name
   - Start Date
   - Silkworm Variety
   - Number of DFLs
   - Rearing House
   - Egg Source
4. Tap **Save**.

### Recording an Expense

1. Navigate to **Expenses**.
2. Tap **+** to add a new expense.
3. Select the category, enter the amount, date, and optionally link it to a Batch.
4. Tap **Save**. The Dashboard financial summary updates automatically.

### Recording Income

1. Open the **Income** module.
2. Tap **+** and enter sale details (buyer, quantity, rate, grade).
3. The profit calculations on the Dashboard and Reports update in real-time.

### Daily Feeding

1. Open **Today's Feedings** from the Dashboard.
2. Select the Batch, enter the leaf type, quantity, and feeding time.
3. Health observations and environmental readings can be added alongside feeding logs.

### Harvesting a Batch

1. Navigate to the **Harvest** module.
2. Tap **+** and select the Batch to harvest.
3. Enter gross weight, net saleable weight, rejected weight, and moisture content.
4. Grade the cocoons and save. Income records can then be created from the harvest.

## Reports

Navigate to **Reports** from the Dashboard to access:

- **Financial Reports**: Monthly expenses, income, and profit trends.
- **Production Reports**: Yield analysis, batch comparisons, and mortality trends.
- **Export**: Download reports as CSV for external analysis.

---

## Backup & Restore

1. Go to **Settings → Backup & Restore**.
2. Tap **Create Backup** to save a snapshot of your entire database.
3. Backups are stored locally on your device and verified with checksums.
4. To restore, select a backup file and confirm. The app will replace the current database.

> **Warning**: Restoring a backup will overwrite all current data.

---

## Settings

- **Farm Profile**: Set your farm name, owner, address, and contact info.
- **Preferences**: Choose Light/Dark theme, temperature units, weight units.
- **About**: View app version and open-source licenses.
